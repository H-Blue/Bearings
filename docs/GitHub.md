# Bearings GitHub setup

Repository: [H-Blue/Bearings](https://github.com/H-Blue/Bearings), public, owned by the signed-in `H-Blue` account. Default branch: `main`. Local `main` tracks `origin/main` at `https://github.com/H-Blue/Bearings.git`.

The owner requested GitHub setup for later Hacklanta submission and explicitly chose public visibility. The owner also explicitly instructed **not to submit the project**. Repository setup does not submit a Devpost entry, a Google Form, or any other hackathon material.

The [Hacklanta GitHub section](https://aluminum-soprano-222.notion.site/Hacklanta-2026-Hacker-Guide-3b81ccc4ed5c80f4b717c0ccc4b5df54#c5e8ee29f2bf4d9d954266fce5486f5c) requires a public repository containing all project code. The [submission checklist](https://aluminum-soprano-222.notion.site/Hacklanta-2026-Hacker-Guide-3b81ccc4ed5c80f4b717c0ccc4b5df54#21d69774e8d84e66914a2acacb016437) calls for a useful README and either a working demo link or clear run instructions; links must remain accessible throughout judging.

The README provides download/clone and Xcode simulator instructions, app features, the Apple-only runtime stack, test results and limits, and development/icon provenance. The guide permits AI tools and requires disclosure of work predating the event. Existing commit history and source provenance are preserved; this setup does not claim project eligibility or complete the separate write-up/video requirements.

## Published scope

The published `main` branch includes the native app, Xcode project/shared scheme, accepted compass/map icon, asset catalog/privacy manifest, data/editor/UI tests, project generator, README and maintained documentation. Existing source commits and their authorship are preserved.

Local signing changes, owner working briefs/source artwork, build logs/results/screenshots, journal stores and credentials are excluded. Only `main` was pushed. Local Codex checkpoint refs were not mirrored to GitHub.
